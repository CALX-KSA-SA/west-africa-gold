# Africa Bridge Guide - West Africa Gold Investment 🌍✨

## 🎯 نظرة عامة
موقع احترافي لعرض فرصة استثمارية ذهبية في غرب أفريقيا - مشروع تعدين ذهب متوسط الحجم بموارد مؤكدة 1.84 مليون أونصة.

## 🚀 المميزات الرئيسية

### ✨ التصميم
- تصميم حديث وجذاب بصرياً
- فيديو خلفية متحرك مع تأثيرات بصرية قوية
- Glass Morphism Cards
- أيقونات جميلة ومبدعة
- تأثيرات Shimmer و Glow
- تحريكات سلسة عند التمرير

### 📊 المحتوى
- **إحصائيات دقيقة**: 1.84M أونصة ذهب
- **معدل استخلاص**: 80% 
- **الإنتاج السنوي**: ~81,072 أونصة
- **الإيرادات المتوقعة**: $1.21B
- **التكلفة الرأسمالية**: $131.4M

### 🎨 الأقسام
1. **Hero Section** - عرض رئيسي قوي
2. **Overview** - نظرة عامة على الفرصة
3. **Project Stats** - حجم الموارد المعدنية
4. **Production** - الطاقة الإنتاجية
5. **Revenue** - الإيرادات والعوائد
6. **Infrastructure** - البنية التحتية (10 عناصر)
7. **Investment** - نقاط القوة (6 نقاط)
8. **Why Invest** - أسباب الاستثمار (5 نقاط)
9. **Risks** - المخاطر (شفافية كاملة)
10. **Requirements** - متطلبات تقديم العرض
11. **Contact** - معلومات الاتصال
